## Scavenger Hunt

Usually by the time your have reached this paragraph, you are confronting
some text that looks like:
```
Something called the AltVEnv Python module downloaded a bunch of Python modules
into a holding area and needs you to manually approve each one for security
purposes.  Remember the program author decided to put you through this tedium
rather the alternate tedium of setting up something called a Python virtual
environment.  The program author made the call.  For this particular program,
you only go through the tedium once.

The module preview list is:
1. MODULE_NAME_1: "DOC_LINE_1" at URL_1
...
N. MODULE_NAME_N: "DOC_LINE_N" at URL_N

To finish the approval process copy and paste title from the each web page
at the prompt:

1. Copy and paste title from URL_1 here:
...
N. Copy and paste title from URL_N here.

Thank all modules approved, resuming program execution.
```
That is the process.
