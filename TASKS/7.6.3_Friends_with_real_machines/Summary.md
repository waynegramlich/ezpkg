# Summary of `T.fwrm` Friends with real machines

Closed 2026-10-22 without asking friends (Wayne): GitHub's runners do
more, faster, and again on every change.  `check.yml` covers Windows
and both kinds of Mac with Python 3.11-3.15, python.org's macOS Python
without certificates and a real console where the question is
answered (`--console`, ConPTY on Windows); `email_check.yml` runs a
release as a friend's on all three.  Chad's old Mac had already run the
Quick Start (`T.towam`).  Not covered: the Microsoft Store, Homebrew
and Apple Pythons.  Related: `T.towam`, `T.gar`, `I.wmau`.
