# Summary of `T.sit` Separate the issue tracker

Done by `ai_contexts` rather than a separate `issue` program: `ISSUES/`
is a collection like `TASKS/`, one directory per issue, each with a
tag such as `I.htdwcp` and its own priority column, listed and shown by
`aic`.  The issues were migrated from `ISSUES.md` on 2026-10-07 under
their old tags.  `ISSUES.md` itself was moved here as `History.md` on
2026-10-12, and the comments in `alt_venv.py` that named it now name
`ISSUES/`.
