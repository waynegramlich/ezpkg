# 7.2 Set up hardware 2FA

Two FIDO2/WebAuthn security keys, a primary and a backup kept
elsewhere, registered on GitHub, pypi.org and test.pypi.org.  An
authenticator app and saved recovery codes stay as the last resort.
With Trusted Publishing (`T.wrw`) the GitHub account is as much a gate
on publishing as PyPI's, so it gets the same keys.  No API token is
ever made.
